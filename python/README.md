# Python Samples

This directory contains various Python coding samples and utility scripts.

## Subdirectories

* [fizzbuz](fizzbuz/): A simple implementation of the classic FizzBuzz problem.
* [simple_rest_api](simple_rest_api/): A basic WSGI-compliant REST API that checks if a string is a pangram (contains all letters of the English alphabet).
* [sslcert](sslcert/): A utility to retrieve and report the validity and security details of SSL certificates for a list of servers.
