# Tcl Samples

> **Note:** This sample was generated using an LLM based on the `bash/` directory.

## fizzbuzz.tcl

A Tcl implementation of the classic FizzBuzz problem. Prints numbers from a start
value to an end value, replacing multiples of 3 with "Fizz", multiples of 5 with
"Buzz", and multiples of both with "FizzBuzz".

**Usage:**

```bash
# Run with defaults (1 to 10)
tclsh fizzbuzz.tcl

# Custom start value (to 10)
tclsh fizzbuzz.tcl 5

# Custom start and end values
tclsh fizzbuzz.tcl 1 100
```
