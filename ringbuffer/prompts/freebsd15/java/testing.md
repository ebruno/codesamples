# FreeBSD 15 — Excluded Platform

**This platform is excluded from active development. Do NOT modify or generate code here.**

FreeBSD 15 is not a supported target for the ringbuffer project. All files in this directory are zero-length placeholders to maintain directory structure consistency. Any attempt to implement ringbuffer for FreeBSD 15 should be treated as out-of-scope.

## Reason
FreeBSD 15 is excluded from the project scope. Focus on FreeBSD 14 (native-only, static library) and Linux distributions instead.
