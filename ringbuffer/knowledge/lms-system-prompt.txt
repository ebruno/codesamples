## Architecture
The ringbuffer implements a three-stage pipelined architecture (Read → Transform → Write). Each stage runs in its own thread, communicating through a fixed-size array of shared slots with independent atomic index counters.

Pipeline stages:
1. **Read thread** fills slots from an input file descriptor, marks each slot `readyfortransform` when full. On EOF, marks the final slot with `LAST_BUFFER_TO_TRANSFORM`.
2. **Transform thread** applies a user-supplied transform function to each slot's data in-place, computes an atomic checksum (MD5/SHA256/SHA512), and marks the slot `readyforwrite`.
3. **Write thread** writes transformed data to an output file descriptor, clears the slot buffer, and resets it to `readyforread`. On the last buffer, it flushes (fsync) before signaling completion.

Status transitions: readyforread → processing_read → readyfortransform → processing_transform → readyforwrite → processing_write → readyforread
EOF propagation: LAST_BUFFER_TO_TRANSFORM → LAST_BUFFER_TO_WRITE

## Key Types

### BufferStatus (slot state machine)
- READYFORREAD(0), READYFORTRANSFORM(1), READYFORWRITE(2)
- PROCESSING_READ(3), PROCESSING_TRANSFORM(4), PROCESSING_WRITE(5)
- EMPTY(6), FULL(7)
- LAST_BUFFER_TO_TRANSFORM(8), LAST_BUFFER_TO_WRITE(9)
- PENDING_READ(10), PENDING_TRANSFORM(11), PENDING_WRITE(12)
- STATUS_ERROR(13)

### ChecksumAlgorithm (per-slot)
- NONE(0), MD5(1), SHA256(2), SHA512(3)

### LogLevel (verbosity)
- TRACE(0), DEBUG(1), INFO(2), WARNING(3), ERROR(4), CRITICAL(5)

## Quick Start — C++
```cpp
#include "ringbuffer.hpp"
#include "swtr_ringbuffer_impl.hpp"
using namespace swtr;

auto transform = [](std::vector<uint8_t>& data, size_t& size) {
    for (size_t i = 0; i < size; ++i)
        if (data[i] >= 'a' && data[i] <= 'z') data[i] -= 32;
};

auto rb = std::make_unique<SwtrRingBuffer>(4, BufferStatus::readyforread, 4096, nullptr, transform);
rb->set_read_fd(STDIN_FILENO);
rb->set_write_fd(STDOUT_FILENO);
rb->start(); rb->wait(); rb->stop();
```

## Quick Start — Java
```java
import swtr.*;

TransformFunction transform = (data, size) -> {
    for (int i = 0; i < size; ++i)
        if (data[i] >= 'a' && data[i] <= 'z') data[i] -= 32;
};

SwtrRingBuffer rb = new SwtrRingBuffer(4, BufferStatus.READYFORREAD, 4096, null, transform);
rb.setReadFd(0); rb.setWriteFd(1);
rb.start(); rb.awaitTermination(); rb.stop();
```

## Quick Start — Python
```python
from swtr_ringbuffer import SwtrRingBuffer, BufferStatus

rb = SwtrRingBuffer(num_slots=4, initial_status=BufferStatus.READYFORREAD, buffer_size=4096)
rb.set_transform_fn(lambda data, size: None)  # identity transform
rb.set_read_fd(0); rb.set_write_fd(1)
rb.start(); rb.wait(); rb.stop()
```
