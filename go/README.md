# Go Samples

## fizzbuzz

Process the numbers 1 to 100.
Writes "Fizz" when the number is a multiple of 3,
"Buzz" when the number is a multiple of 5,
"FizzBuzz" when the number is a multiple of both 3 and 5,
and the number itself otherwise.

See [fizzbuzz/README.md](fizzbuzz/README.md) for build and usage instructions.

## numberadder

Adds two arbitrarily large numbers stored one digit at a time in a slice.
The second number is reversed before addition.

See [numberadder/README.md](numberadder/README.md) for build and usage instructions.

Both examples can be built with Bazel or Make.
